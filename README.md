## Installation

### Windows

Laden Sie das Windows-Setup herunter, öffnen Sie die EXE-Datei und folgen Sie den angezeigten Installationsschritten.

### Android

Laden Sie die APK-Datei auf das Android-Gerät herunter und öffnen Sie sie. Falls Android nachfragt, erlauben Sie die Installation aus dieser Quelle.

## Hinweise

Die von GitHub zusätzlich angebotenen Archive mit der Bezeichnung „Source code“ sind keine Installationsdateien. Verwenden Sie für die Installation die oben verlinkte EXE- oder APK-Datei.

Klassenalarm ergänzt bestehende Alarmierungs- und Notfallabläufe. Die App ersetzt keinen Notruf.

Wenn Sie Unterstützung bei der Installation benötigen, wenden Sie sich bitte an Ihre Klassenalarm-Ansprechperson.
